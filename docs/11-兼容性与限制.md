# 11 · 兼容性与限制

## 支持范围

- **最低** Android 10（API 29）。
- **目标/编译** API 35（Android 15）。已在 API 35 模拟器验证启动与主要页面。
- 覆盖 API 29–35 的差异处理如下。

## 版本差异处理

## 已声明的重点处理

- **前台服务**：`CoreService` 声明 `dataSync|mediaProjection|connectedDevice|specialUse`，
  Android 14 下按需组合类型并提供 `PROPERTY_SPECIAL_USE_FGS_REASON`。
- **屏幕录制**：Android 14 在用户同意录屏后先升级 mediaProjection 类型前台服务，再取得投影；
  同一个授权只创建一次 VirtualDisplay。
- **电池优化**：提供「忽略电池优化」入口，未授权时后台仍受系统调度约束。
- **Shizuku**：`newProcess` 在 13.x 为私有，使用反射；若 Shim 变化则回退 APP/无障碍。

## 已知限制

1. **不内置 Tailscale 客户端**：本应用依赖系统已登录的 Tailscale（或其地址）。
   设置页的 Auth Key 仅本地保存，用于记录/后续扩展，不参与连接建立。见 [12](12-功能清单与状态.md)。
2. **VPN 为预留**：仅接管 10.66.0.0/24，未实现用户态协议栈，暂不能代理任意应用到对方 IP；
   请改用端口转发。
3. **锁定权限差异**：普通权限使用全屏悬浮问题页和返回拦截，不能保证屏蔽 Home 与通知栏。
   设备所有者模式使用 Lock Task 与状态栏策略；普通设备管理员、ADB/Shizuku 和无障碍授权不等于设备所有者。
4. **屏幕帧为逐帧 WebP**（非硬编 H.264 视频流）：兼容性最好、实现简单，但带宽高于 H.264。
   现有链路带宽不足时可调低 `w/fps/quality`。
5. **音频回放捕获**只能捕获允许被捕获的音频（部分应用会 opt-out）。
6. **协议未端到端加密**：安全性依赖 Tailscale 隧道。
7. **从电脑直接调用 API** 的便捷程度取决于系统对 `content call` 的支持，建议同签名辅助程序。
