# 10 · 构建与交付

## 环境要求

- JDK 17（`java -version` 应显示 17）。
- Android SDK：platform `android-35`、build-tools `35.0.0`。
- Gradle：使用仓库自带 wrapper（8.9）。
- macOS/Linux/Windows 均可；本仓库在 macOS 上验证。

## 首次配置

```bash
cd 代码/nekosakana
export ANDROID_HOME=$HOME/Library/Android/sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
echo "sdk.dir=$ANDROID_HOME" > local.properties
```

## 构建命令

```bash
./gradlew :app:assembleDebug        # 调试包
./gradlew :app:assembleRelease      # 发布包
./gradlew :app:compileDebugJavaWithJavac   # 仅编译
```

若依赖未缓存且离线，去掉 `--offline`。

## 安装

```bash
adb install -r -t app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
```

## 交付产物

构建后把 APK 复制到用户下载目录（交付流程）：

```bash
cp app/build/outputs/apk/debug/app-arm64-v8a-debug.apk ~/Downloads/nekosakana-debug.apk
```

## 自检清单

当前原生库及交付 APK 支持 arm64-v8a。原生库源码修改和重建方式见 `native/README.md`。

Tailnet 使用应用内 netstack，不启动系统 VPN，不改变其他应用的路由。局域网模式使用系统已有路由（包括其他 Tailscale 客户端建立的网络），不需要 Auth Key。返回键先返回上一页，在主页保留界面；连接由前台服务维持，启动和服务恢复时自动重连。系统强制停止、厂商省电限制或网络断开仍会影响后台连接。
