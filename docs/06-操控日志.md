# 06 · 操控日志

`core/ControlLog.java` 记录双方互相发起的操作，持久化到
`Android/nekosakana/logs/control.log`（每行一个 JSON）。

## 记录结构

```json
{"ts":1730000000000,"dir":"in","type":"control.tap","detail":"x=540 y=1200"}
```

| 字段 | 含义 |
| --- | --- |
| `ts` | 毫秒时间戳 |
| `dir` | `in`=对方操作我；`out`=我操作对方；`sys`=本机事件 |
| `type` | 操作类型，如 `control.tap`、`apps.freeze`、`forward.open`、`lock.submit` |
| `detail` | 明细 |

## 写入点

引擎收到任意请求会写一条 `in`；本地对外发起的关键操作（聊天以外的控制类）会写 `out`；
服务启停、锁屏、无障碍连接、FTP/VPN 等写 `sys`。

## 查看

- 应用内「日志」页显示最近 300 条（`ControlLog.asText(300)`）。
- 远程可通过 `control.log` 请求获取对方的操控日志。
- `dir` 渲染为箭头：`←` 对方→我，`→` 我→对方，`·` 本机。

## 清理

`ControlLog.clear()` 清空内存并删除文件；当前未在 UI 暴露按钮，可按需在设置页扩展。
