# 02 · 协议与链路

## 帧格式

每条 TCP 链路上的最小单位为「帧」：

```
┌───────────────┬──────────────────┬───────────────┬──────────────┐
│ headerLen (4B)│ header (JSON)    │ bodyLen (4B)  │ body (bytes) │
│ big-endian int│ UTF-8, 可含 id/t │ big-endian int│ 二进制负载    │
└───────────────┴──────────────────┴───────────────┴──────────────┘
```

- `header` 是 JSON 对象，至少包含 `t`（类型）。请求再带 `id`。
- `body` 于文件/图像/音频帧承载二进制；其余帧 `bodyLen=0`。
- 实现见 `net/Link.java`。写操作加锁，读在独立线程。

## 连接策略

- 双方都监听 `Config.port()`（默认 `45871`），也都会主动连接对方的该端口。
- 发送时选择「主链路」：优先出站链路，否则第一条可用链路；因此两个方向各走一条链路，
  不会重复推送。
- 收到重复 `id` 的帧会被丢弃（`NetHub.seen`，容量 2048）。

## 握手与心跳

- 建链后立即发送 `hello`：`{name,node,version,backend,ts}`。Tailnet 模式依赖 Tailscale 节点认证；局域网/系统网络模式不做应用层密钥认证。
- 每 2s 发送 `ping{ts}`，收到后回 `pong{ts}`；收到 `pong` 计算 `lastRtt`。
- `NetHub.statusText()` 汇总“已连接 / 链路数 / 延迟”。

## 消息类型一览

### 握手与保活
`hello`、`ping`、`pong`。

### 请求/响应
请求方任意类型带 `id`；被请求方执行后回 `result{re,ok,msg,data?}`（可带 body）。

| 类型 | 载荷 | 说明 |
| --- | --- | --- |
| `screen.shot` | — | 一次性截图，`result.body` 为 WebP |
| `screen.start` | `w,fps,quality,audio` | 开始向请求方推送 `screen.frame` |
| `screen.stop` | — | 停止推流 |
| `audio.start/stop` | `rate,channels,bitrate` | 音频推流 |
| `control` | `action,x,y,x1..,duration,text,key` | 注入点击/滑动/长按/文字/按键 |
| `apps.list` | `system` | 应用列表 |
| `apps.frozen` | — | 已冻结应用 |
| `apps.freeze/unfreeze/launch/forceStop/uninstall` | `pkg` | 应用管理 |
| `usage.current/stats/events` | `since,limit` | 使用情况 |
| `devstate.get/set` | `key,value` | 设备状态读/写 |
| `sensor.get` | — | 传感器 |
| `location.get/track` | `limit` | 定位与轨迹 |
| `install` | body=APK | 安装 |
| `shell.exec` | `cmd,timeout` | 远端 shell |
| `lock.config/engage/release` | `config` | 锁定页控制 |
| `control.log` / `log.get` | `limit` | 日志 |
| `perm.status` | — | 权限状态 |

### 事件（无需响应）
`screen.frame`、`audio.frame`、`chat.text`、`chat.file`、`lock.event`、`notify`。

### 隧道（端口转发）
`tunnel.open{host,port}`、`tunnel.data{id,dir}` + body、`tunnel.close`。

## 请求封装

`engine/Engine.java`：

- `request(type,payload,body,timeout)`：阻塞等待，返回 `Reply{ok,data,body,message}`。需工作线程调用。
- `sendEvent(type,payload[,body])`：单向事件。
- 收到的 `screen.frame`/`audio.frame`/`chat.*` 分发给已注册的 `*Listener`。

## 安全说明

协议本身**不内置加密或应用层认证**。Tailnet 模式依赖 Tailscale 的点对点加密；局域网/系统网络模式不加密且不认证，仅用于可信网络或已有 Tailscale/VPN 加密隧道。
`ApiProvider` 对外调用要求同签名或携带 `api_token`。
