| 获取对方屏幕（自动截图 + 高压缩 WebP 传输） | ✅ | `screen.shot` / `ScreenShare`；连续共享优先 adb 直采，系统录屏回退 |

## 网络服务

| 需求 | 状态 | 实现 |
| --- | --- | --- |
| 启动时开本地服务器 | ✅ | `NetHub` ServerSocket |
| 转发对方本地服务器 | ✅ | `PortForward`（应用层隧道） |
| 可选 VPN 让其他应用像局域网访问 | 🟡 | `VpnBridge` 预留子网（见 08） |
| 启动时开 FTP | ✅ | `FtpServer` 免配置自启，仅回环 `127.0.0.1:2222`，根目录 `/sdcard`（隧道数据源） |
| 访问对方 `/sdcard` | ✅ | 内置 `FtpBridge`，本机 `ftp://127.0.0.1:2221`（解析 PASV/EPSV 数据端口），自动开启 |
| 开放 API 供其他应用调用 | ✅ | `ApiProvider`（见 09） |
| 连接电脑时可用电脑控制 | 🟡 | 同签名/`adb` 经 API 调用 |
