# 05 · 日志与归档

## 目录布局

所有应用自身文件都位于外部存储的 Android 目录下（`core/Store.java`）：

```
首选：/storage/emulated/0/Android/nekosakana/
兜底：/storage/emulated/0/Android/data/app.nekosakana/files/   （外部不可写时）

Android/nekosakana/
├── logs/
│   ├── nekosakana.log      运行日志（实时追加）
│   ├── control.log         操控日志（JSON Lines）
│   ├── usage-events.log    应用进入/离开历史
│   ├── track.log           定位轨迹（JSON Lines）
│   └── archive/
│       └── log-<ts>.7z     归档后的高压缩日志
├── chat/history.log        聊天记录（JSON Lines）
├── media/                  收到的文件
├── apk/                    待安装/已接收的 APK
└── tmp/                    临时文件（7z 中间产物）
```

`Store.isPublicRoot()` 指示当前是否使用了公共 `Android/nekosakana` 目录。

## 实时日志

`core/Logx.java`：

- 每条日志形如 `MM-dd HH:mm:ss.SSS [I] tag: message`。
- 写入在单线程执行器中进行，避免阻塞调用方。
- 内存保留最近 800 行，供 UI「日志」页快速展示。
- 文件超过 **2 MiB** 触发滚动：用 7z 压缩到 `logs/archive/log-<时间戳>.7z`，随后清空原文件。

## 7z 归档

`core/Archive.java` 使用 `commons-compress` 的 `SevenZOutputFile`，压缩算法 **LZMA2**：

- `compress(List<File>, File)`：将若干文件压成一个 `.7z`。
- `extract(File, File)`：解压到目录。
- `compressText(name, text)`：内存中压缩文本。

滚动阈值/目录常量集中在 `Logx`，如需调整改 `ROTATE_BYTES` 与 `RING_MAX`。
