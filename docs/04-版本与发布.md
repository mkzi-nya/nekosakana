# 04 · 版本与发布

## 版本约定（硬性）

- **versionCode 始终为 `1`，永不改变。**
- **versionName 规则：**
  - 新增功能：次版本号 `+1`（如 `1.0.0` → `1.1.0`）。
  - 仅修复、未新增功能：修订号 `+1`（如 `1.1.0` → `1.1.1`）。
- 当前版本：`1.1.0`。

versionCode 声明在 `app/src/main/AndroidManifest.xml` 的
`<manifest android:versionCode="1">`；`app/build.gradle` 仅声明 `versionName`。
构建后可校验：

```bash
aapt2 dump xmltree --file AndroidManifest.xml app/build/outputs/apk/debug/app-arm64-v8a-debug.apk | grep versionCode
# A: ...:versionCode=1
```

发布新版本时：新增功能递增次版本号，仅修复递增修订号；versionCode 保持不变。

## 构建

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
echo "sdk.dir=$ANDROID_HOME" > local.properties

./gradlew :app:assembleDebug      # 调试包
./gradlew :app:assembleRelease    # 发布包（未混淆）
```

产物：

| 变体 | 路径 |
| --- | --- |
| debug | `app/build/outputs/apk/debug/app-arm64-v8a-debug.apk` |
| release | `app/build/outputs/apk/release/app-arm64-v8a-release.apk` |

仅打包 arm64-v8a。文件分享由自研的 `core/FileSharer`（ContentProvider）实现。
