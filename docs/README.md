## 快速开始（开发者）

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
```

版本号始终为 `0`，版本名始终为 `0.1.x`，详见 [04-版本与发布](04-版本与发布.md)。
